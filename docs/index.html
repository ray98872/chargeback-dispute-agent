The math — why not just softmax?

A softmax of 0.97 is not a probability you can act on. Neural networks are systematically over-confident, and an agent that moves money on miscalibrated scores is a liability, not a product. The fix here is split conformal prediction: hold out a calibration set the model never trained on, score how "non-conforming" each example is, and judge every new dispute against that empirical distribution.

nonconformity s(x, y) = 1 − softmax_y(x) p-value per class p_k = ( #{ s_i ≥ s(x, k) } + 1 ) / ( n + 1 ) credibility = max_k p_k → does this input conform to anything seen? confidence = 1 − second max p_k → how decisively are rivals rejected? prediction set @95% = { k : p_k > 0.05 }

The agent acts autonomously only when confidence > 0.95 and the 95% prediction set is a singleton. By construction the true class falls inside the prediction set at least 95% of the time on exchangeable data — a finite-sample, distribution-free guarantee, not an empirical hope. Measured on the held-out test set: 92.0% coverage (n=100 — within the finite-sample variance the theory predicts around the 95% target), average set size 0.92, test accuracy 100%.

Same family of techniques as my MSc dissertation — GPU-accelerated conformal prediction — applied to a production-shaped problem.

Pipeline

Synthetic data engine

Faker-built SQLite bank: 5,000 transactions, 500 free-text disputes across Fraud, Merchant Error and Policy Violation — with shared noise clauses so classes deliberately overlap and the escalation path actually exercises.

generate_data.py · sqlite + faker

PyTorch fine-tune

Plain training loop — no Trainer abstraction. AdamW, linear LR decay, gradient clipping, stratified 60/20/20 train/calibration/test split. The calibration split is never trained on; that independence is what makes the guarantee hold.

train_model.py · distilbert-base-uncased

Agentic runner

Iterates pending disputes, classifies, then acts: autonomous UPDATE to "Resolved — Auto Refunded" above threshold, otherwise "Requires Human Review". Every decision lands in an audit log table.

Decisions that matter

  • The agent never sees ground truth. True labels exist only for training and the dashboard's backtest panel — at decision time the agent acts purely on model output, keeping the evaluation honest.
  • Threshold on calibrated confidence, not softmax. The 95% gate means the error rate on autonomous refunds is statistically controlled — on this run the agent was 100% accurate on the disputes it actioned alone.
  • Escalation is a feature, not a failure. The 4.2% of disputes the model couldn't decide at the 95% level are exactly the ones a human should see — sorted lowest-confidence-first in the queue.
  • Audit everything. An autonomous agent executing financial SQL without an audit trail is a compliance incident waiting to happen. Every action is logged with its full statistical justification.
  • Zero cost, fully local. No paid APIs anywhere: synthetic data, a free base model fine-tuned on CPU, SQLite, Streamlit. The whole MVP reruns from scratch with four commands.
